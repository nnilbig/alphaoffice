# alphaoffice

西區交易室：用 three.js 做的等角像素風 AI 交易辦公室。

## 配置

- 辦公區 6 席（只有桌子與雙螢幕），前排三席有人
- 會議室：4 隻白貓討論今日重點觀察
- 主管室
- 茶水間：斑紋貓提供情緒價值與交易修心策略
- 走道伺服器機櫃

## 成員（Q 版貓咪）

| 成員 | 負責 | 螢幕配色 |
| --- | --- | --- |
| 棕貓 | 前一日・今日・明日的國際事件與數據 | 黃白像素 |
| 黑貓 | 前一日・今日・明日的產業數據 | 紅黑像素 |
| 橘貓 | 前一日・今日・明日的盤勢數據 | 藍黃像素 |
| 斑紋貓 | 情緒價值・交易修心（茶水間） | — |
| 白貓 ×4 | 會議室：今日重點觀察 | — |

## 使用

直接用瀏覽器開啟 `index.html`（需要網路載入 three.js CDN），或開啟 GitHub Pages。

- 拖曳旋轉、滾輪縮放
- 點貓咪或右側名單查看分工
- 「像素感」切換像素／高清渲染

右側頻道訊息目前為示意內容。
