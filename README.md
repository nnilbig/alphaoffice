# alphaoffice

西區交易室：用 three.js 做的等角像素風 AI 交易辦公室。

## 配置

- 辦公區 6 席（只有桌子與雙螢幕），前排三席有人
- 會議室：白貓們討論今日重點觀察
- 主管室：灰貓 Earl 在看書，可查看今日交稿狀態
- 茶水間：斑紋貓 Miso 提供情緒價值與交易修心策略
- 走道伺服器機櫃

## 成員

| 名字 | 貓 | 負責 | 交稿（交易日，台北時間） |
| --- | --- | --- | --- |
| Mocha | 棕貓 | 前一日・今日・明日的國際事件與數據 | 07:30 |
| Onyx | 黑貓 | 前一日・今日・明日的產業數據 | 07:45 |

| Earl | 灰貓 | 主管 | — |

尚未交稿的貓，螢幕會暗著；交稿後亮起。

## 報告資料

報告存在 Claude 頁面的資料庫，由排程任務每天寫入，所以只有在 Claude 上登入開啟才看得到報告與「問牠」功能。這個 repo 的 `index.html` 單獨開啟時只會顯示辦公室與成員，報告區會顯示讀不到。

## 操作

- 拖曳旋轉、滾輪縮放
- 點貓咪或右側名單打開報告（摘要、數據表、前一日／今日／明日、資料來源）
- 「像素感」切換像素／高清渲染
